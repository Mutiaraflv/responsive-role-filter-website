# Role Explorer — RuangKarya

Komponen role explorer responsif untuk menjelajahi lowongan berdasarkan department. Data posisi dibuat secara mock dan disimpan di `app.js`; tidak membutuhkan backend atau proses build.

## Cara menjalankan

Buka `index.html` langsung di browser, atau jalankan server lokal dari folder ini, misalnya `python -m http.server 8000`, lalu buka `http://localhost:8000`.

## Fitur

- Default menampilkan seluruh posisi.
- Filter department memperbarui kartu dan jumlah posisi secara langsung.
- Empty state tersedia bila department terpilih tidak memiliki posisi.
- Layout menyesuaikan layar desktop dan mobile.
